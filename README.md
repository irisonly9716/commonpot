# CommonPot

Shared expense accounts for households, roommates and small groups: log and split expenses, see who owes whom, get budget alerts in real time, and keep a private personal ledger.

> Work in progress (Sprint 1). Production URL, setup and deployment guides are added in issue #19.

## Stack

Next.js 16 + React 19 + TypeScript 6, Tailwind CSS 4 + shadcn/ui, Supabase (PostgreSQL, Auth, Realtime), Vitest and Playwright, deployed on Vercel. Exact versions and commands are in [AGENTS.md](AGENTS.md).
