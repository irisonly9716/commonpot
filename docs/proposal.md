Project Name: CommonPot – Shared Accounts for Households and Groups
Project 2 Proposal @Jay Choudhary @ge.ge

Description:
CommonPot is a shared expense account for households, roommates, couples and other small groups. People who live or travel together share many costs, such as rent, utilities, groceries, internet or a weekend trip. Most groups track these in a group chat, in a spreadsheet one person maintains, or from memory. Receipts get lost, one person ends up doing all the bookkeeping, and nobody is sure who owes whom until an awkward conversation at the end of the month.

CommonPot gives each group one account that every member can see and update. Members log an expense, choose who shares it, and split it equally or by exact amounts. Balances update automatically, and new expenses appear on everyone's screen in real time, so the whole group always sees the same numbers. A "Settle up" view suggests a short list of payments that clears all debts. The group admin invites members, manages roles and sets monthly budgets by category, such as $400 for groceries, and every member gets an alert when spending reaches 80% or 100% of a budget. Each member can see their own monthly spending and the group's total, with charts by category and month. Each user also has a private personal ledger that adds up their own expenses and their shares from every group. A site admin oversees the platform, and a documented public REST API lets users connect other tools, such as a script that imports a bank export. CommonPot records payments between members but never moves real money.

User Stories:
1. As a household organizer, I want to create a shared account and invite my roommates or family with a link, so that everyone records shared costs in one place.
2. As a member, I want to log an expense with who paid and who shares it, split equally or by exact amounts, so that costs are divided fairly without doing math in a chat.
3. As a member, I want new and edited expenses to appear on my screen in real time, so that I always see the same numbers as everyone else.
4. As a member, I want to see who owes whom and record payments when we settle up, so that we can clear debts without arguing over the numbers.
5. As a member, I want to see my own monthly spending and the group's total spending, each with charts, so that I know what I spend and which shared costs are growing.
6. As a user, I want a private personal ledger that adds up my own expenses and my share of every group, so that I know what I really spend each month.
7. As a group admin, I want to set monthly budgets by category and have everyone alerted when we get close to a limit, so that we can adjust before the month ends.
8. As a group admin, I want to manage members, roles and categories, and delete expenses that shouldn't be there, so that the account stays accurate when people move in or out.
9. As a site administrator, I want to view platform activity and suspend abusive accounts, so that the service stays safe for everyone.
10. As a developer, I want a documented REST API for groups, expenses and balances, so that I can connect CommonPot to other tools.
